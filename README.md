# Sprite Forge Studio

Editor de pixel art e preparação de recursos 2D para Godot 4. O projeto reúne ferramentas de edição, animação, organização de ativos, exportação e fluxos experimentais de assistência local.

## Estado

O software está em desenvolvimento. Consulte a documentação do projeto local para o escopo funcional e as limitações conhecidas. Recursos de IA são opcionais; o editor e as ferramentas principais não dependem de serviços pagos.

## Desenvolver

1. Instale Godot 4.7.2.
2. Abra `project.godot` no Godot.
3. Pressione F5 para executar o editor.

Código principal: `core/`, interface: `ui/`, serviços auxiliares: `services/`, testes: `tests/`.

Os scripts `Run-Tests.ps1` e `Build-Windows.ps1` documentam os fluxos locais de validação e empacotamento. O repositório público contém o código-fonte; dados artísticos privados, resultados locais e arquivos gerados não fazem parte desta publicação.
